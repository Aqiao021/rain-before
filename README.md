# 雨停之前

一部关于雨天、咖啡馆和一个叫林雨的女孩的网页视觉小说。共 4 条路线、5 个结局，女主角和老板娘有日语配音。

**v3.3 在线游玩：** https://aqiao021.github.io/rain-before/v3.3/

**旧版在线游玩（保留）：** https://aqiao021.github.io/rain-before/

v3.3 独立放在 `v3.3/`，包含新版程序及图片、配音素材。GitHub Pages 使用预设剧情模式；AI 对话需要单独部署服务端。

- 策划、剧本统筹、美术生成与验收：作者本人
- 程序、剧本初稿、背景音乐：AI 协作（Claude）
- 立绘、背景、CG：AI 图像生成后人工筛选
- 日语配音：Style-Bert-VITS2 生成（模型与授权见游戏内“设置 → 制作名单”）
